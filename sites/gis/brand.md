## Identity

The route-and-contour mark combines a continuous asset route, two recognizable endpoints and the surrounding terrain. It should read as a map symbol at favicon size. In a wordmark, write `SkarionGIS` in one run and use the olive accent on `GIS`. Avoid inserting a space or replacing the name with initials in buyer-facing copy.

## Voice and visuals

Start with the record the buyer needs to use. Name the route or asset class, relevant sources, owner schema and output. Describe what the reviewer can verify. Use concrete verbs such as map, reconcile, trace and validate. Claims about owner approval, native integrations, field surveys, data residency and turnaround need project-specific support.

Use maps and source-to-asset diagrams with a legible route line, common asset symbols and visible exception markers. Keep a synthetic label on demo data. Before using basemaps, photography or client file excerpts, document permissions, exact attribution, intended reuse and the redactions made. The website logo, cartographic illustration and social source were created for this site. They contain synthetic geometry and need no third-party credit. The site uses system fonts and has no font downloads.
