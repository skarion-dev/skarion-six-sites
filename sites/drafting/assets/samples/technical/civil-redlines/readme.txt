Fictional source data and drawings for portfolio review. Workflows and values are illustrative.
Issue 01 is a review sample. Do not use these files for construction, permitting or asset records.

Extract all files first. Open civil-redlines.dwg with survey-base.dwg in the same folder. The host uses a relative attachment.
Compare C-101 and C-201 with the SK-01/SK-02 packet, then review C-301 and the engineer redline register.

CAD format: AutoCAD 2018 DWG (AC1032), model units in feet. Layouts identify the 17 x 11 in sheets.
The matching PDF is the supplied issue plot. The DWG contains named layers, editable model-space entities, paper-space notes and linked viewports.
PDF colors and plot settings can look different with local CAD templates and fonts.
The converted DWG was reopened through ODA File Converter and checked against the source CAD for entities, named layers, layouts and viewports. Autodesk AutoCAD was unavailable for this review.
