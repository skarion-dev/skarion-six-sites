## Approval steps

1. Assign a production lead, GIS acceptance reviewer and website owner. Record the scope and target schema in the project record.
2. Complete the technical review. Use unique asset IDs, an agreed CRS, valid geometry, current revision references, explicit uncertainty and validated import or exchange.
3. Review filenames, attribute and metadata values, basemap licenses, attachment indexes and screenshots for source permissions. For a synthetic demonstration, label the map, downloadable files and accompanying captions.
4. Record approval, date, review notes and public usage limits before adding any finished sample to the public site. For client work, verify Skarion's documented role and publishing permission first.
