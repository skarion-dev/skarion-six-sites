# Zihad’s 50-hour sprinkler CAD sprint

Goal. Prove that one drafter and one named reviewer can transfer approved sprinkler changes into clean files, keep open issues visible, and hand off one checked draft. Use synthetic or authorized redacted files. Have a qualified sprinkler designer prepare the source exercise and reserve time for feedback and a blind retest.

| Hours | Exercise | Evidence to produce |
| ---: | --- | --- |
| 8 | Learn system vocabulary, sheet anatomy, roles and the differences among NFPA 13, 13R and 13D. Read selected fundamentals and talk through controlled examples with the reviewer. | Annotated source sheet and a decision-owner checklist. |
| 10 | Set up one client-like AutoCAD or Revit template. Open and reference supplied files, check units and revisions, and plot a clean sheet. | Native working file, PDF proof, and environment notes. |
| 12 | Transfer approved redlines from one base revision. Add a planted conflicting instruction and track it as open for the designer. | Draft drawing, source-to-change register and check plot. |
| 8 | Compare supplied trade views, record a possible overlap and apply only the reviewer-approved disposition in a separate training revision. | Side-by-side review view and issue register with revisions and owner. |
| 8 | Extract a review sheet and schedule from a designer-supplied accepted model or exercise index. Verify identifiers and keep held items out of the issued extract. | Draft sheet, schedule and model-to-output crosswalk. |
| 4 | Complete a blind redline retest, self-check it, and review it with the lead. Record how long production and review took. | Annotated revision, scorecard, timing and list of corrections. |
| **50** | | |

## Supervised acceptance

Before a paid pilot, have the reviewer confirm all intentional design changes trace to written source decisions, all planted ambiguities are assigned, output opens in the target version, sheet and register revisions agree, and the checker can reproduce the output from the source. Repeat any exercise with an unresolved material error. Track senior review time alongside production time. Resume a paid pilot only with a confirmed reviewer and work scope.

## Learning materials

- **Trade fundamentals.** NFSA’s [Layout Technician Pathway](https://member.nfsa.org/Events/layout-technician) gives the broader route. Its program lists about 25 hours of self-paced Fundamentals plus a separate three-day instructor-led Application. Schedule the complete course separately. [NFPA’s comparison of the three standards](https://www.nfpa.org/news-blogs-and-articles/blogs/2024/03/12/comparing-nfpa-13-nfpa-13r-and-nfpa-13d) supports vocabulary and scope familiarization. The reviewer identifies the adopted edition and project basis.
- **Software.** Use one stack for the sprint. [AutoSPRINK vendor training](https://autosprink.com/training/library) fits a contractor using AutoSPRINK. If the first buyer works in Revit, use the [Udemy sample lessons and course outline](https://www.udemy.com/course/bim-sprinkler-system-fire-protection-in-revit-mep/) to evaluate the course and [Autodesk’s Revit coordination reference](https://help.autodesk.com/cloudhelp/2025/ENU/Revit-Collaborate/files/GUID-890A9FE0-EFF4-4CFB-9E81-B0DE1A132BEC.htm) for the scope and limits of interference checks.
- **Videos and GPT.** Use [NFPA Joe’s channel](https://www.youtube.com/channel/UCdBz218gVtqKbaCqdNhfkoQ) for illustrations and questions to take to the reviewer. Use GPT with authorized training snippets to define terms, quiz the drafter and compare the supplied markup list with the issue register. For example, “List the source ID and disposition for each instruction. Mark missing approval as a question for the designer.” The reviewer independently checks code interpretations and calculations.
- **Experience.** [NICET Water-Based Systems Layout](https://www.nicet.org/certification-programs/electrical-and-mechanical-systems/water-based-systems-layout/certification-requirements/) describes the six-month, two-year and five-year minimum experience levels, core experience and other certification requirements. Log supervised work separately from training. Confirm eligibility with the credentialing body rather than counting the sprint as project experience.

## First paid batch and later scope

Use the [redline exercise](../../../sites/sprinkler/portfolio-review.md) as a sales example. Have an experienced, authorized reviewer direct the actual work. Start with one client-approved sheet. Agree the source, version, review time and permitted access in writing. Before selling model coordination or shop extraction, prove first that the actual client’s models, reference links, version and issue handoff survive the exchange.

Keep system selection, head locations and coverage decisions, hydraulics, final engineering, and permit, fabrication and installation release with the authorized team.
